A bounded, uncertainty-aware support tool for reflective coping practice. It is not a crisis, medical, or diagnostic service.

Method

This demo uses a structured micro-skill prompt, a rule-based safety layer, and an uncertainty score derived from token log probabilities. When risk is high, the system does not deliver the draft. It routes to a narrower fallback instead.
